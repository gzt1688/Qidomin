## 📖 简介

**Qidomin** 是一个基于 **Tauri 2 + React + Rust** 的 Windows 桌面整理软件。它把"桌面整理"变成一块块**透明分区**：你把软件快捷方式、散落的文件、常用文件夹分别归入不同的分区，就像在桌面上放了一个个透明的收纳盒。

- ✅ 每个分区是一个**透明面板**，可自由移动、调节大小、锁定
- ✅ 拖文件进分区 = **真实移动文件**（不再是"眼不见心不烦"的假整理）
- ✅ **3 种分区类型**：软件、文件、文件夹，各司其职
- ✅ 每分区独立**背景色 / 透明度**，图标大小可调
- 🧩 内置 **便签 / 股票 / 黄历 / 毛泽东诗词** 桌面小组件
- ✅ 布局可**导出 / 导入**，系统重装不丢失
- ✅ 极轻量：不常驻后台扫描，只在你操作时工作

## 🚀 快速上手

1. **启动**：运行 Qidomin，托盘出现图标，桌面上出现默认的 3 个分区：
   - 🟦 **软件**（青色）— 放软件快捷方式
   - 🟩 **文件**（绿色）— 放任意文件
   - 🟪 **文件夹**（蓝色）— 链接真实文件夹
2. **使用**：
   - 把桌面上（或文件夹里）的快捷方式 / 文件 **拖进分区**，即完成整理
   - **分区之间互拖**：把一个分区里的文件 / 文件夹拖到另一个分区上，它就真的搬过去了
     （按住 **Ctrl** 拖 = 复制一份，不放 Ctrl = 移动；跨盘、关联文件夹分区之间都支持）
   - 鼠标拖动**分区标题栏**移动分区，拖动**边缘/角落**调整大小
   - 点击标题栏右侧 **⋮** 打开分区菜单
   - 设置页「**桌面组件**」开启便签 / 股票 / 黄历 / 毛泽东诗词小组件
3. **托盘**：右下角托盘图标（右键）→ 显示/隐藏、新建分区、设置、一键整理、退出

## 🗂️ 分区类型

| 类型 | 图标 | 用途 | 拖放行为 |
| --- | --- | --- | --- |
| **软件** `software` | 🟦 | 存放软件快捷方式（`.lnk`） | 拖入 = 移动快捷方式 |
| **文件** `file` | 🟩 | 存放任意文件 / 文件夹 | 拖入 = 移动文件 |
| **文件夹** `folder` | 🟪 | 链接一个真实文件夹，展示其内容 | 拖入 = **真实移入**该文件夹 |

### 🔀 分区之间互拖（移动 / 复制）

把一个分区里的图标拖到另一个分区上松手，文件就真的过去了：

| 操作 | 结果 |
| --- | --- |
| 直接拖 | **移动**（从原分区消失，出现在目标分区） |
| 按住 **Ctrl** 拖 | **复制**（原分区保留，目标分区多一份） |
| 拖回自己所在的分区 | 调整图标排列位置（不搬运文件） |

- 支持 **文件、文件夹** 一起拖
- 支持 **跨盘**：关联文件夹分区指向 D:/E:/U 盘时，自动改成「复制 + 删源」，和资源管理器一致
- 目标分区里已有同名文件时自动加序号（`xxx (1)`），不会覆盖
- **移动后文件仍然记得最初的位置**：以后删掉分区，文件会回到桌面上最初待的地方，
  而不是被退回到另一个分区的隐藏文件夹里

> 搬进 / 搬出后会有一条短暂提示（成功报条数，失败给出原因，例如文件被占用、权限不足）。

**文件夹分区**（快捷文件夹）在分区菜单选择「**链接文件夹…**」，弹出文件管理器选中一个目录后，分区内即实时显示该目录的文件，并支持排序：

| 排序方式 | 说明 |
| --- | --- |
| 名称 | 按文件名（中文按拼音） |
| 时间 | 按修改时间（最新在前） |
| 大小 | 按文件大小（从大到小） |
| 类型 | 按扩展名分组 |

> 文件夹分区不会移动、删除你真实目录里的文件，只做展示与打开。

### 数据与安全

本程序只在两种情况下碰你的文件：**你自己把图标拖进分区**，以及**你自己开启了"自动吸附"**。
除此之外不做任何修改、删除、隐藏。

**分区文件夹的归属判定**（这是全部安全的底线）

- 普通分区的文件夹是程序自己新建的（`<桌面>\<分区名>`），建好后打上「隐藏 + 系统」属性，
  这样桌面上只看到透明分区面板，不会多出一个文件夹图标
- 程序只操作**带这两个属性的、由自己创建的**文件夹。「隐藏 + 系统」既是它的标记，
  也是唯一的准入门：任何要改属性 / 搬空 / 删除 / 重命名目录的操作，
  第一步都先确认这个标记 —— 不是自己建的，直接跳过
- 所以桌面上你自己建的同名文件夹（没有这两个属性）**永远不会**被隐藏、搬空或删除；
  分区名字撞上这种文件夹时，程序会**自动换一个名字**（见下），不去碰你的文件夹
- **快捷访问（关联文件夹）分区**链接的是你自己的目录。程序对它**只读**：
  展示内容、监听变化以刷新列表。绝不移动、删除、隐藏它，解散该分区也只是撤掉这块面板
- 改完隐藏属性后会主动通知资源管理器刷新，所以「取消隐藏」是**立刻**生效的 ——
  不需要你按 F5 才能在桌面上看到那个文件夹

**分区命名（新建分区 / 关联文件夹）**

- **关联文件夹分区**：名字默认**就是被关联文件夹的文件夹名**（选 `I:\UG\社长传图`
  → 面板就叫「社长传图」）。撞名时整名加序号（「社长传图 2」），不会退化成「文件夹 N」
- 其它分区由程序在后台统一取号：`文件 N` / `文件夹 N` / `软件 N` / `新分区 N`，
  N 从**已有的最大序号 + 1** 往下取，并自动跳过数据库和桌面上已被占用的名字
- 所以「新建分区」不会因为重名而失败。取到的名字和你要的不一样时，
  分区面板右下角会提示实际用的是哪个名字
- 创建失败（例如目标没有写权限）也会给出明确提示，不会"点了没反应"

**解散分区 = 只解散分组，一步到位，不再弹任何确认框**

| 场景 | 结果 |
| --- | --- |
| 普通分区 → 解散 | 分区里的文件按搬运记录退回**整理前的原始位置**（原来在桌面就回桌面，原来在哪个文件夹就回那个文件夹；位置被占用时自动加序号），分区文件夹随之删除。**文件只是被搬回去，仍是原来的图标 / 快捷方式，不改名、不改属性、不删除** |
| 快捷访问分区 → 解散 | 只撤掉面板，关联的文件夹和里面的文件**原样保留**，没有被移动、删除或隐藏的风险 |

> 「回到原始位置」的判定：**只要当初的位置可用，就一定回那儿**（比如文件原本在桌面上，
> 就回桌面；原本在某个子文件夹里，就回那个子文件夹）。只有当记录里的原始位置已经不可用
> （历史遗留的脏数据 —— 指向的是另一个分区的隐藏文件夹）时，才退回**桌面根目录**，
> 让你一眼能找到。**任何情况下都不会把文件塞进另一个分区的隐藏文件夹。**
>
> 点「解散分区」就立刻执行，以前那个"先确认、再二选一（移回桌面 / 留在原文件夹）"的
> 两级弹窗已经去掉了 —— 中间那两步只是多点两次鼠标，还容易点错。

**其它保证**

- 退出程序时，分区里的文件会先回到桌面（下次启动按记录收回），
  保证程序没运行时桌面是"正常"的；**关联文件夹里的内容不参与这个来回搬运**
- 解散时若还有文件被别的程序占用、退出不来，会**明确报错并保留分区**，
  不会假装成功、也不会把文件留在隐藏目录里让你找不到
- 数据存于本地数据库，不上传任何云端

## 🧩 桌面小组件

除了分区，设置页的「**桌面组件**」里还可以开启 **4 个桌面小组件**——它们与分区一样是**独立透明窗口**，可自由移动、缩放、锁定，外观（背景色 / 透明度）独立可调：

| 小组件 | 说明 |
| --- | --- |
| 📝 **便签** | 多标签记事本，随手记录，本地保存 |
| 📈 **股票** | 自选股实时行情，红涨绿跌，自动刷新 |
| 🧧 **黄历** | 农历、干支、宜忌、节气倒计时，本地推算 |
| 🖋️ **毛泽东诗词** | 内置诗词库，随机 / 搜索，可自动轮换 |

### 📝 便签

- **多标签页**：新建 / 重命名 / 删除标签，按主题分类记录
- **算式自动计算**：一行以 `=` 结尾就自动算出结果（`6+3=` → `6+3=9`），支持 `+ - * / ^` 与括号，可连着往下算（`6+3=9+1=10`）；右键菜单里可关闭
- 每条便签独立保存，重启不丢
- 独立窗口：位置、大小、锁定、背景色、透明度

### 📈 股票

- 添加 / 删除**自选股票**，实时刷新行情
- 展示最新价、涨跌幅、涨跌额，A 股配色（**红涨绿跌**）
- 刷新间隔可选：3 / 5 / 10 / 30 / 60 秒
- 独立窗口外观配置

### 🧧 黄历

- 农历日期、干支纪年、**宜 / 忌**
- **节气倒计时**：如「还有 N 天到冬至」，直观掌握节气
- 全部**本地推算**，零网络请求、零隐私上传

### 🖋️ 毛泽东诗词

- 内置诗词库（离线可用），**随机展示**一首
- 支持**关键词搜索**（如「风雪」「昆仑」）
- 可开启**自动轮换**（默认每 20 秒换一首）

> 4 个小组件与分区体验一致：独立透明窗口、可拖动缩放锁定、布局随「保存桌面」一并导出导入。

## ❓ 常见问题

**Q：托盘出现 2 个图标？**
A：程序内置单实例保护，任何方式重复启动都会被立即拒绝；请使用最新版本。

**Q：拖文件进分区，原文件不见了？**
A：这是「真实整理」——文件被移动到桌面的隐藏分区文件夹中。删除分区时文件会自动退回原位置。

**Q：分区标题栏消失了 / 分区不见了？**
A：点击托盘图标或托盘菜单「显示/隐藏分区」即可恢复显示。

**Q：新建了分区，也提示建好了，但桌面上看不到新面板？**
A：分区面板一定会被放在**主显示器工作区内的空位**上；如果屏幕上的空位已经排满，
新面板会落在"被压得最少"的位置（可能和某个分区轻微重叠），但**绝不会跑到屏幕外面**。
老版本按分区序号递推排位置，分区数量一多就会排到屏幕下方之外，看起来就是"建好了但看不见" ——
升级后启动一次，那些跑到屏幕外的分区会被自动收回到可见区域内。

**Q：系统重装后分区布局丢了？**
A：重装前在设置页「**保存桌面**」导出布局，装好后「**导入桌面**」即可还原分区位置与类型。

**Q：是否支持 Linux / macOS？**
A：当前为 Windows 专用，后续视需求考虑。
