## 📖 简介

**Qidomin** 取名来自福州话 擦桌面， 一款 Windows 桌面整理软件。它把"桌面整理"变成一块块**透明分区**：你把软件快捷方式、散落的文件、常用文件夹分别归入不同的分区，就像在桌面上放了一个个透明的收纳盒。

- ✅ 每个分区是一个**透明面板**，可自由移动、调节大小、锁定
- ✅ 拖文件进分区 = **真实移动文件**（不再是"眼不见心不烦"的假整理）
- ✅ **3 种分区类型**：软件、文件、文件夹，各司其职
- ✅ 每分区独立**背景色 / 透明度**，图标大小可调
- 🧩 内置 **便签 / 股票 / 黄历 / 毛泽东诗词** 桌面小组件
- ✅ 布局可**导出 / 导入**，系统重装不丢失
- ✅ 极轻量：不常驻后台扫描，只在你操作时工作

## 🚀 快速上手

1. **启动**：运行 Qidomin，托盘出现图标，桌面上出现默认的 3 个分区：
   - 🟦 **软件**（青色）— 放软件快捷方式
   - 🟩 **文件**（绿色）— 放任意文件
   - 🟪 **文件夹**（蓝色）— 链接真实文件夹
2. **使用**：
   - 把桌面上（或文件夹里）的快捷方式 / 文件 **拖进分区**，即完成整理
   - 鼠标拖动**分区标题栏**移动分区，拖动**边缘/角落**调整大小
   - 点击标题栏右侧 **⋮** 打开分区菜单
   - 设置页「**桌面组件**」开启便签 / 股票 / 黄历 / 毛泽东诗词小组件
3. **托盘**：右下角托盘图标（右键）→ 显示/隐藏、新建分区、设置、一键整理、退出

## 🗂️ 分区类型

| 类型 | 图标 | 用途 | 拖放行为 |
| --- | --- | --- | --- |
| **软件** `software` | 🟦 | 存放软件快捷方式（`.lnk`） | 拖入 = 移动快捷方式 |
| **文件** `file` | 🟩 | 存放任意文件 | 拖入 = 移动文件 |
| **文件夹** `folder` | 🟪 | 链接一个真实文件夹，展示其内容 | 拖入文件**不移动**（仅展示） |

**文件夹分区**（快捷文件夹）在分区菜单选择「**链接文件夹…**」，弹出文件管理器选中一个目录后，分区内即实时显示该目录的文件，并支持排序：

| 排序方式 | 说明 |
| --- | --- |
| 名称 | 按文件名（中文按拼音） |
| 时间 | 按修改时间（最新在前） |
| 大小 | 按文件大小（从大到小） |
| 类型 | 按扩展名分组 |

> 文件夹分区不会移动、删除你真实目录里的文件，只做展示与打开。

## 🎛️ 功能详解

### 分区标题栏

| 元素 | 功能 |
| --- | --- |
| 彩色圆点 | 分区类型标识（颜色可自定义） |
| 标题 | **双击**进入重命名（回车确认 / Esc 取消） |
| `N 项` | 分区内条目计数 |
| 🔓/🔒 | **锁定开关**：锁定时分区不可拖动、不可缩放 |
| **×** | **彻底删除分区**（文件自动退回整理前的原始位置） |
| **⋮** | 分区菜单：新建 / 外观 / 排序 / 链接文件夹 / 删除 |

### 分区菜单（⋮）

- **新建分区** — 当前分区旁快速新建一个同类型分区
- **外观** — 单独设置本分区**背景色**与**透明度**
- **排序** — 文件夹分区的内容排序方式
- **链接文件夹…** — 选择要展示的真实目录（仅文件夹分区）
- **删除分区** — 带确认：可「删除并退回文件」或「仅删除分区，文件保留」

### 设置页

| 设置项 | 说明 |
| --- | --- |
| 分区透明度 / 背景色 | 新建分区的全局默认外观 |
| 图标大小 | 分区内图标显示尺寸 |
| 吸附开关 | 拖动分区时是否相互吸附 |
| 开机自启 | 登录时自动运行 |
| 一键整理 | 自动把桌面散乱图标归入对应分区 |
| **桌面组件** | 便签 / 股票 / 黄历 / 毛泽东诗词 的开启开关 |
| **保存桌面** | 导出布局（分区位置、大小、颜色、类型）为文件 |
| **导入桌面** | 从布局文件还原（系统重装后一键恢复） |

### 数据与安全

- 拖入分区的文件会被**真实移动**到桌面的隐藏分区文件夹中
- **删除分区时，文件自动退回整理前的原始位置**（原位置被占用时自动加序号），不会丢文件
- 数据存于本地数据库，不上传任何云端

## 🧩 桌面小组件

除了分区，设置页的「**桌面组件**」里还可以开启 **4 个桌面小组件**——它们与分区一样是**独立透明窗口**，可自由移动、缩放、锁定，外观（背景色 / 透明度）独立可调：

| 小组件 | 说明 |
| --- | --- |
| 📝 **便签** | 多标签记事本，随手记录，本地保存 |
| 📈 **股票** | 自选股实时行情，红涨绿跌，自动刷新 |
| 🧧 **黄历** | 农历、干支、宜忌、节气倒计时，本地推算 |
| 🖋️ **毛泽东诗词** | 内置诗词库，随机 / 搜索，可自动轮换 |

### 📝 便签

- **多标签页**：新建 / 重命名 / 删除标签，按主题分类记录
- 每条便签独立保存，重启不丢
- 独立窗口：位置、大小、锁定、背景色、透明度

### 📈 股票

- 添加 / 删除**自选股票**，实时刷新行情
- 展示最新价、涨跌幅、涨跌额，A 股配色（**红涨绿跌**）
- 刷新间隔可选：3 / 5 / 10 / 30 / 60 秒
- 独立窗口外观配置

### 🧧 黄历

- 农历日期、干支纪年、**宜 / 忌**
- **节气倒计时**：如「还有 N 天到冬至」，直观掌握节气
- 全部**本地推算**，零网络请求、零隐私上传

### 🖋️ 毛泽东诗词

- 内置诗词库（离线可用），**随机展示**一首
- 支持**关键词搜索**（如「风雪」「昆仑」）
- 可开启**自动轮换**（默认每 20 秒换一首）

> 4 个小组件与分区体验一致：独立透明窗口、可拖动缩放锁定、布局随「保存桌面」一并导出导入。

## ❓ 常见问题

**Q：托盘出现 2 个图标？**
A：程序内置单实例保护，任何方式重复启动都会被立即拒绝；请使用最新版本。

**Q：拖文件进分区，原文件不见了？**
A：这是「真实整理」——文件被移动到桌面的隐藏分区文件夹中。删除分区时文件会自动退回原位置。

**Q：分区标题栏消失了 / 分区不见了？**
A：点击托盘图标或托盘菜单「显示/隐藏分区」即可恢复显示。

**Q：系统重装后分区布局丢了？**
A：重装前在设置页「**保存桌面**」导出布局，装好后「**导入桌面**」即可还原分区位置与类型。

**Q：是否支持 Linux / macOS？**
A：当前为 Windows 专用，后续视需求考虑。
