# Qidomin 鼠标快捷键通用方案

> 版本：v1・适用于所有 Windows 鼠标，无需安装任何品牌驱动



***

## 一、方案概述

**核心思路**：只使用 **Windows 标准鼠标键**（所有鼠标硬件级支持，系统原生识别），做到 "任何鼠标、任何用户、零驱动、零依赖"。



| 特性  | 说明                               |
| --- | -------------------------------- |
| 通用性 | 不绑定罗技 / 雷蛇等任何品牌，带侧键的普通鼠标即可用      |
| 依赖  | 零驱动、零后台程序（注册为系统全局热键）             |
| 性能  | 热键注册方式**零常驻开销**，不干扰系统，符合轻量要求     |
| 扩展性 | 侧键以外的鼠标专用键（罗技 G 键等）属厂商私有功能，Qidomin 不参与 |



***

## 二、可绑定按键表

### 通用键（所有鼠标）



| 按键                  | 说明       | 通用性                |
| ------------------- | -------- | ------------------ |
| **X1**              | 侧键①（前进键） | ✅ 所有带侧键鼠标          |
| **X2**              | 侧键②（后退键） | ✅ 所有带侧键鼠标          |
| **中键**              | 中键单击     | ✅ 所有鼠标             |
| **X1 / X2 + Ctrl**  | 组合键      | ✅                  |

| **X1 / X2 + Alt**   | 组合键      | ✅                  |
| **滚轮上 / 下**（可选）     | 连续滚动触发   | ✅ 所有鼠标（需轻量钩子，默认关闭） |

> 基础可用绑定约 
>
> **10 个组合**
>
> ，足够覆盖常用操作。

## 三、冲突处理设计（关键）

全局热键注册后，**该键会被本软件接管**，其他程序收不到。因此：



1. **总开关（默认关闭）**：不开启时完全不抢占任何键，零影响

2. **每项独立开关**：只启用你真正要用的绑定

3. **冲突提示**：若检测到绑定键已被其他程序占用，给出提示而非静默抢占

> 例：绑定 X2 后，浏览器 "后退" 会失效 —— 这是全局热键的必然行为，用户知情后自行取舍。

## 四、技术实现（架构简述）



| 能力                            | 实现方式                          | 开销      |
| ----------------------------- | ----------------------------- | ------- |
| X1 / X2 / 中键 / 组合键 | Windows `RegisterHotKey` 全局热键 | 零常驻开销   |
| 滚轮上 / 下                       | 轻量鼠标钩子（可选，默认关）                | 极低，可随时关 |

> 热键配置持久化在软件本地配置中，
>
> **换鼠标、重装软件均可保留**
>
> 。

## 五、设置说明（用户操作）

### 操作步骤



1. 打开 **设置** → 找到「**快捷键**」分组

2. 打开**总开关**（首次使用）

3. 点击「**添加绑定**」：

* 选择**按键**（X1 / X2 / 中键 / 双击中键 / 组合）

* 选择**动作**（见下方推荐表）

* 按需开 / 关该项

1. 保存即生效（无需重启）

### 推荐绑定方案



| 动作              | 推荐键           | 说明           |
| --------------- | ------------- | ------------ |
| 显示 / 隐藏全部分区     | **X2**        | 最顺手，一键收起桌面   |
| 打开快速搜索          | **X1**        | 侧键常按，即搜即达    |
| 新建分区            | **Ctrl + X1** | 低频操作用组合，避免误触 |
| 一键整理            | **Ctrl + X2** | 低频操作         |
| 打开便签            | **中键**        | 随手记录         |
| 快速切换（翻页 / 上一分区） | **滚轮上 / 下**   | 可选开启         |

## 六、罗技 G 键：已放弃的路线

曾经设计过「用 G HUB 把 G 键一次性映射成 F13~F24，之后由 Qidomin 接管」这条路，
**实测不可行，已放弃**：G HUB 把映射写在储存位 `_m1`，而鼠标实际活动的储存位是 4，
退出 G HUB 后按 G 键什么都不会发生。

Qidomin 侧的相关代码（HID++ 探针、设置页「罗技鼠标 G 键」区块、F 键监听）**已全部删除**，
本项目不再支持任何鼠标专用键。踩坑结论见 `docs/罗技G键-HID++直连研究结论.md`。

## 七、常见问题

**Q：绑定了没反应？**

A：① 检查总开关与该项开关是否开启；② 检查该键是否被其他程序（如浏览器、游戏）占用。

**Q：绑定后浏览器前进 / 后退失效？**

A：正常现象 —— 全局热键会接管该键。不想要就关闭该项绑定或使用组合键。

**Q：换鼠标 / 重装系统后要重新设置吗？**

A：不需要。绑定配置保存在 Qidomin 本地配置中，跟随软件迁移；新鼠标只要支持对应按键即可直接使用。

**Q：会不会影响游戏？**

A：总开关关闭时零影响；开启时仅占用你绑定的键。游戏内建议关闭或换用组合键。
